# Chapter 1: Getting Started with Rust

This chapter introduces the fundamental toolchain and project anatomy of Rust applications.

## 📌 Topics Covered

1. **Rust Installation & Version Check**:
   - `rustc --version`
   - `cargo --version`
2. **Cargo Anatomy**:
   - `Cargo.toml`: Package manifest defining dependencies, editions, and metadata.
   - `src/main.rs`: Entry point for executable binaries.
   - `src/lib.rs`: Entry point for library crates.
3. **Running the Code**:
   ```bash
   cargo run -p section_2
   ```
